# ROS 2 Rover

ROS 2 Humble workspace for the Rover project.

## Packages

- `rover_drone_following` – Logic for drone following an ArUco marker mounted on rover
- `rover_mavlink_communication` – translation between FCU <--> ROS2
- `rover_navigation` – autonomous motion and navigation logic

## Requirements

- Ubuntu 24.04
- ROS 2 Humble
- `colcon`
- `rosdep`

## Frequent commands
Only folder for building packages is **~/rover_ws**!!!
```bash
cd ~/rover_ws
```

Source the ROS2 for ros2 commands (ros2 run, ros2 launch etc.)
```bash
source /opt/ros/humble/setup.bash
```

Source the workspace/packages after successful build.

```bash
source ~/workspace/install/setup.bash
```
## Workspace Structure

```text
rover_ws/

├── build/
├── install/
├── log/
├── src/
│   ├── rover_drone_following/
│   ├── rover_mavlink_communication/
│   └── rover_navigation/
├── README.md
```

The `build`, `install` and `log` directories are generated by `colcon` and are not stored in Git.

## Install Dependencies

```bash
cd ~/rover_ws

source /opt/ros/humble/setup.bash

rosdep install \
    --from-paths src \
    --ignore-src \
    --rosdistro humble \
    -y
```

## Build

```bash
cd ~/rover_ws

source /opt/ros/humble/setup.bash

colcon build --symlink-install
```

Source the workspace after a successful build:

```bash
source ~/rover_ws/install/setup.bash
```

## Clean Build

Use a clean build after changing package configuration, dependencies or entry points:

```bash
cd ~/rover_ws

rm -rf build install log

source /opt/ros/humble/setup.bash

colcon build --symlink-install
source install/setup.bash
```
