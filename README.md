# DRC Rover

ROS 2 Jazzy workspace for the Rover project.

## Packages

- `rover_autonomy` – autonomous motion and navigation logic
- `rover_controls` – command validation, control and base simulation
- `rover_bringup` – launch files, URDF model and RViz configuration

## Requirements

- Ubuntu 24.04
- ROS 2 Jazzy
- `colcon`
- `rosdep`

## Workspace Structure

```text
rover_ws/
├── README.md
├── src/
│   ├── rover_autonomy/
│   ├── rover_bringup/
│   └── rover_controls/
├── build/
├── install/
└── log/
```

The `build`, `install` and `log` directories are generated by `colcon` and are not stored in Git.

## Install Dependencies
### First: Install ROS 2 (based on your system)
For Ubuntu 24.04: https://docs.ros.org/en/jazzy/Installation/Ubuntu-Install-Debs.html

```bash
cd ~/rover_ws

source /opt/ros/jazzy/setup.bash

rosdep install \
    --from-paths src \
    --ignore-src \
    --rosdistro jazzy \
    -y
```

## Build

```bash
cd ~/rover_ws

source /opt/ros/jazzy/setup.bash

colcon build --symlink-install
```

Source the workspace after a successful build:

```bash
source ~/rover_ws/install/setup.bash
```

## Run the RViz Simulation

```bash
source /opt/ros/jazzy/setup.bash
source ~/rover_ws/install/setup.bash

ros2 launch rover_bringup rover_rviz.launch.py
```

The launch file starts:

- the test motion node,
- the safety watchdog,
- the simple rover base simulator,
- the robot state publisher,
- RViz.

## Node Architecture

```text
test_motion_node
        │
        │ /cmd_vel_raw
        ▼
safety_watchdog_node
        │
        │ /cmd_vel
        ▼
base_simulator_node
        │
        ├── /odom
        ├── /rover/moving
        └── TF: odom → base_link
```

## Main Nodes

### `test_motion_node`

Package:

```text
rover_autonomy
```

Publishes test velocity commands for the rover.

Output topic:

```text
/cmd_vel_raw
```

### `safety_watchdog_node`

Package:

```text
rover_controls
```

Checks whether velocity commands are still being received.

If commands stop arriving, the watchdog publishes a zero velocity command and stops the rover.

Input topic:

```text
/cmd_vel_raw
```

Output topic:

```text
/cmd_vel
```

### `base_simulator_node`

Package:

```text
rover_controls
```

Implements a simple planar kinematic simulation.

It integrates:

- linear velocity,
- angular velocity,
- rover position,
- rover orientation.

Input topic:

```text
/cmd_vel
```

Output topics:

```text
/odom
/rover/moving
```

Published TF transform:

```text
odom → base_link
```

## Main Topics

| Topic | Message type | Description |
|---|---|---|
| `/cmd_vel_raw` | `geometry_msgs/msg/Twist` | Requested velocity before safety validation |
| `/cmd_vel` | `geometry_msgs/msg/Twist` | Validated rover velocity |
| `/odom` | `nav_msgs/msg/Odometry` | Simulated rover odometry |
| `/rover/moving` | `std_msgs/msg/Bool` | Indicates whether the rover is moving |
| `/robot_description` | `std_msgs/msg/String` | URDF robot description |
| `/tf` | `tf2_msgs/msg/TFMessage` | Dynamic coordinate transforms |
| `/tf_static` | `tf2_msgs/msg/TFMessage` | Static coordinate transforms |

## Publish a Manual Velocity Command

Drive forward:

```bash
ros2 topic pub --rate 10 \
    /cmd_vel_raw \
    geometry_msgs/msg/Twist \
    "{linear: {x: 0.5}, angular: {z: 0.0}}"
```

Rotate in place:

```bash
ros2 topic pub --rate 10 \
    /cmd_vel_raw \
    geometry_msgs/msg/Twist \
    "{linear: {x: 0.0}, angular: {z: 0.5}}"
```

Drive along an arc:

```bash
ros2 topic pub --rate 10 \
    /cmd_vel_raw \
    geometry_msgs/msg/Twist \
    "{linear: {x: 0.5}, angular: {z: -0.3}}"
```

Stop publishing with:

```text
Ctrl+C
```

The safety watchdog should stop the rover after the configured timeout.

## Clean Build

```bash
colcon build --symlink-install
source install/setup.bash
```

## Current Limitations

The current simulation is only a simple kinematic model.

It does not yet simulate:

- wheel rotation,
- motor dynamics,
- wheel slip,
- collisions,
- terrain,
- sensor noise,
- physical inertia,
- Gazebo physics.

RViz is used only for visualization. A physics simulator such as Gazebo can be added later.
